# Development Roadmap

Open Industry Solutions (OIS) targets **10 industry problems per month** (**120 problems annually**), delivered sequentially through structured engineering cycles.

---

## Phase 0 — Programme Foundation (Current)

- [x] Define programme mission, 8 IT domains, and lifecycle governance.
- [x] Establish repository layout, templates, CI validation, and security/engineering standards.
- [x] Catalogue the 10 November 2026 challenges (`01-codeguard` through `10-accesscheck`) with `PLANNED` status.
- [ ] Publish initial foundation repository to GitHub (`main` branch).

---

## Phase 1 — November 2026 Cohort (Projects 01–10)

Each project proceeds individually from `PLANNED` → `DESIGNED` → `IN_DEVELOPMENT` → `VERIFIED` → `RELEASED`, beginning only upon explicit approval:

1. **01 — CodeGuard:** Fast local-first & CI static security/quality guardrail with SARIF output.
2. **02 — ThreatLens:** Normalised security log correlation and IOC triage engine.
3. **03 — UptimePulse:** Synthetic HTTP/TCP/DNS/TLS monitoring with Prometheus & SLO burn-rate alerts.
4. **04 — DeploySafe:** Pre-deployment manifest, config parity, and rollback readiness gatekeeper.
5. **05 — QuerySense AI:** Deterministic database execution-plan analyser with grounded AI explanation.
6. **06 — DataTrust:** Contract-driven pipeline data quality & schema validation engine.
7. **07 — NetScope:** Unified DNS, TCP, TLS, and HTTP path diagnostic CLI.
8. **08 — ITFlow:** Auditable ITSM triage routing and runbook automation workflow engine.
9. **09 — CloudCostIQ:** Read-only multi-cloud idle resource & spend anomaly analyser.
10. **10 — AccessCheck:** Least-privilege IAM & RBAC policy graph auditor.

---

## Phase 2 — Ongoing Monthly Cohorts (December 2026 Onward)

- **Monthly Cadence:** Scope and deliver 10 new industry problems each month across the 8 IT domains.
- **Annual Target:** 120 verified, open-source, production-oriented solutions per year.
- **Continuous Improvement:** Maintain security patches, dependency updates, and community-requested enhancements across released cohorts.
