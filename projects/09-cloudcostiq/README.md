# 09 — CloudCostIQ

- **Status:** `PLANNED`
- **Cohort:** November 2026
- **Domain:** Cloud Infrastructure & FinOps

---

## Problem Statement

Cloud infrastructure costs grow silently through unattached storage volumes, idle non-production compute instances, unmonitored egress patterns, and delayed billing reviews.

## Planned Scope

- Read-only resource and billing dataset analyser identifying idle and orphaned infrastructure.
- Configurable budget thresholds and anomaly detection alerts.
- Actionable FinOps findings exported in JSON and Markdown reports.
