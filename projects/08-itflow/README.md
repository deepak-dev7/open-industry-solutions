# 08 — ITFlow

- **Status:** `PLANNED`
- **Cohort:** November 2026
- **Domain:** IT Service Management (ITSM) & Enterprise Automation

## Problem Statement

Enterprise IT service desks spend significant engineering bandwidth manually triaging repetitive requests, assigning queues, and executing routine operational runbooks without consistent audit trails.

## Planned Scope

- Declarative rule-based ticket classification and SLA priority routing.
- Pluggable runbook executor with explicit human-in-the-loop approval gates.
- Immutable audit log recording every triage and remediation step.
