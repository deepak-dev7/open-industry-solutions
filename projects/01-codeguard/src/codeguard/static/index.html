Using CodeGuard Locally & in CI

CodeGuard shares the same deterministic engine across this web workbench, pre-commit CLI, and GitHub Actions.

CLI Quick Reference

codeguard scan .
codeguard scan --staged
codeguard scan --diff origin/main --format sarif --output codeguard.sarif
codeguard rules
codeguard init
codeguard ui --host 127.0.0.1 --port 8765

Inline Suppressions

legacy_digest = hashlib.md5(payload)  # codeguard: ignore[CG-PY-005]

Security Controls & Architecture

  • Zero Untrusted Execution: Files are inspected statically via Python ast.parse and bounded regular expressions. Uploaded code is never imported or executed.
  • Automatic Secret Redaction: Credential findings mask interior characters before persisting to SQLite or rendering in reports.
  • Path Traversal & Root Guards: Uploaded folder entries reject .. and absolute escapes; local browsing honours configured approved roots.
  • Report Formats: Export persisted runs in JSON, OASIS SARIF v2.1.0 (GitHub Code Scanning compatible), or standalone HTML.
