- **Status:** `PLANNED`
- **Cohort:** November 2026
- **Domain:** Software Engineering & Developer Productivity

---

## Problem Statement

Engineering teams frequently merge code containing hardcoded credentials, high-risk security anti-patterns, and policy violations because enterprise SAST tools can be slow, noisy, or difficult to integrate into local developer workflows.

## Planned Scope

- Fast local-first static inspection for staged diffs and repository trees.
- Secret pattern and high-entropy token detection with configurable allowlists.
- Pluggable rule packs aligned with CWE/OWASP coding guardrails.
- Standardised **SARIF v2.1.0** and JSON output for CI/CD and GitHub Code Scanning integration.
