# 03 — UptimePulse

- **Status:** `PLANNED`
- **Cohort:** November 2026
- **Domain:** Site Reliability Engineering (SRE) & Observability

---

## Problem Statement

Platform teams need lightweight, self-hostable synthetic monitoring that tracks endpoint availability, latency percentiles, and TLS certificate expiry without SaaS lock-in or fragile ad-hoc cron scripts.

## Planned Scope

- Declarative YAML configuration for HTTP(S), TCP, DNS, and TLS probes.
- Prometheus `/metrics` exposition and structured JSON probe logs.
- Multi-window SLO error-budget burn-rate evaluation and webhook alerting.

Specification only (`PLANNED`). No implementation code exists yet.
