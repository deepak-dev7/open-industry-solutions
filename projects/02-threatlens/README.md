# 02 — ThreatLens

- **Status:** `PLANNED`
- **Cohort:** November 2026
- **Domain:** Cybersecurity & Identity (SecOps / IAM)

---

## Problem Statement

Security operations teams must correlate authentication, firewall, and endpoint telemetry across inconsistent log schemas, creating slow manual triage and missed multi-stage anomalies.

## Planned Scope

- Normalised ingestion adapters for common JSON and syslog security event streams.
- Deterministic correlation rules with configurable severity scoring.
- Local IOC (Indicator of Compromise) feed matching and auditable triage reports.
- Read-only analysis mode by default.

Specification only (`PLANNED`). No implementation code exists yet.
